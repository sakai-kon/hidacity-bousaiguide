# ハザードマップデータ

このディレクトリには、岐阜県県土整備部砂防課が公開する土砂災害警戒区域等のGISデータを、Web表示用に変換したGeoJSONを配置します。

## 出典・更新情報

- 出典：岐阜県
- 対象：飛騨市（旧古川町・旧河合村・旧宮川村・旧神岡町）
- データ作成日：令和7年3月31日
- 座標系：EPSG:4326（Web表示用）
- 元データ：EPSG:6675（JGD2011 平面直角座標系 第7系）

## 配置ファイル

- `dosha-keikai.geojson` — 土砂災害警戒区域（イエローゾーン）
- `dosha-tokubetsu.geojson` — 土砂災害特別警戒区域（レッドゾーン）

土砂災害警戒区域等は年度途中でも順次指定されるため、最新の指定状況は岐阜県「土砂災害防止法ポータル」で確認してください。

https://portal.gifugis.jp/sabo/

## 変換上の注意

元データの図形および属性値は変更せず、Web表示のために座標系とファイル形式を変換する前提です。
