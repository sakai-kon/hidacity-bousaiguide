# 防災記事の追加方法

`articles/` フォルダに `.txt` ファイルを追加すると、GitHub Actions が記事一覧とサイト内検索用データを自動生成します。

## 基本形式

```text
---
title: 土砂災害から身を守る
category: 土砂災害
date: 2026-08-20
description: 土砂災害の特徴と避難時のポイントを紹介します。
keywords: 土砂災害, 避難, 大雨, ハザードマップ
---

# 土砂災害から身を守る

ここに本文を書きます。

## まず確認すること

- ハザードマップを確認する
- 避難先を家族と話し合う
```

### メタデータ

- `title`：記事タイトル
- `category`：カテゴリ名。記事一覧のフィルターに使われます。
- `date`：公開日。新しい記事を上に並べます。
- `description`：記事カードと検索結果に表示する短い説明です。
- `keywords`：カンマ区切り。サイト内検索の精度を上げます。

`# 見出し`、`## 小見出し`、`- リスト項目`、空行による段落分けに対応しています。

## 互換性

メタデータを書かない古い記事形式も利用できます。先頭が `# タイトル` なら、その行がタイトルとして使われます。カテゴリなどの指定がない場合は `防災` が使われます。

## 保存場所

```text
articles/
└── your-article.txt
```

ファイルを `main` に追加すると、GitHub Actions が `articles/articles.json` と `search/site-search.json` を自動更新します。
