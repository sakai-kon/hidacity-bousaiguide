# 防災記事の追加方法

このフォルダに `.txt` ファイルを追加すると、GitHub Actions が記事一覧を自動生成します。

## 書き方

先頭行を `# タイトル` にすると、その文字列が記事タイトルになります。

```text
# 土砂災害について

土砂災害は大雨などをきっかけに発生することがあります。

自分の住んでいる地域のハザードマップを確認しておきましょう。
```

`#` 行がない場合は、ファイル名をタイトルとして使います。

## 保存場所

```text
articles/
└── your-article.txt
```

追加後はGitHub Actionsが `articles/articles.json` を自動更新し、サイトの「防災記事」ページに表示します。
